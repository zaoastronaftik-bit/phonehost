# PhoneHost / Shark

PhoneHost запускает Debian через PRoot поверх Android. Команды выполняются в обычном Termux, без `su` и без перепрошивки.

```sh
curl -fL https://raw.githubusercontent.com/zaoastronaftik-bit/phonehost/main/PhoneHost-install.sh -o PhoneHost-install.sh
bash PhoneHost-install.sh
phonehost console
```

Если нужен только новый пульт или PhoneHost уже установлен, запусти `bash PhoneHost-install.sh --launcher-only`. Этот режим обновляет команду в Termux и не запускает настройку Debian, Nginx и SSH.

## Расследование компании

В пульте **Расследование · номер, ник, компания**. Можно указать любые из полей и пропустить остальные. Режим работает прямо в Termux и не требует запуска веб-сервера или установки Debian.

```sh
phonehost investigate --site 'https://shop.example.org' --handle @shop --phone '+37120001000'
phonehost investigate --registration 40003032949
phonehost investigate --company 'Bloomberg Finance L.P.' --json
```

Первый адрес и контакт — пример формата. Для проверки подставь реальные деловые реквизиты.

- Сайт и до двух его страниц контактов дают описание деятельности, публичные рабочие номера, ссылки на профили и объявленные регистрационные данные. Сайт компании и второй сайт для сверки можно передать отдельными флагами `--site`.
- [Открытые данные реестра предприятий Латвии](https://data.gov.lv/dati/eng/dataset/uz) сверяются по регистрационному номеру. [GLEIF](https://www.gleif.org/en/lei-data/gleif-api) проверяется по LEI или ищет точное совпадение названия. Совпадение по названию — кандидат, а отсутствие LEI не означает, что компании нет.
- Для России по умолчанию отчёт направляет к [официальной выписке ЕГРЮЛ](https://egrul.nalog.ru/). Автопроверка российских **юрлиц** по ИНН или ОГРН и код ОКВЭД доступны с `PHONEHOST_DADATA_KEY` через [API DaData](https://dadata.ru/api/find-party/). DaData — отдельный источник, официальный остаётся в отчёте.
- Для поиска по всему вебу без известного сайта нужен ключ [Brave Search API](https://api-dashboard.search.brave.com/documentation/guides/authentication) в `PHONEHOST_BRAVE_KEY` и флаг `--discover` (в пульте появится отдельный вопрос). Провайдер получает поисковый запрос. В отчёт попадают не все результаты выдачи, а страницы, на которых найдена структурированная информация об организации и точное совпадение исходного признака. Это ограниченный поиск, не полный список приложений и аккаунтов.
- `--bill путь` сравнивает подписанные поля телефона и регистрационного номера из локального счёта. TXT читается сразу. Для PNG, JPEG и WebP нужен установленный в Termux Tesseract. Язык OCR по умолчанию `eng`; для установленных английского и русского можно задать `PHONEHOST_OCR_LANG=eng+rus`. Файл и полный текст не отправляются. Распознанный идентификатор юрлица используется для проверки в реестре.
- По умолчанию снимок не сохраняется. `--case shop` создаёт локальный JSON-файл в `~/.phonehost/investigations/`. Повтори те же исходные данные с тем же именем, чтобы увидеть разницу на страницах, прочитанных оба раза. `--json` печатает отчёт в stdout.

Shark различает наличие юрлица в источнике, публикацию контакта на странице и неподтверждённую связь. Он не узнаёт, кто владеет частным номером или каким номером зарегистрирован аккаунт, и не делает вывод «мошенник» по совпадению.

Тесты без сети и ключей:

```sh
python -m unittest discover -s tests -v
```

### Больше публичных источников

- Пульт автоматически проверяет публичные организации GitHub и публичные группы GitLab по введённому деловому нику. Частные аккаунты через API пользователей не запрашиваются.
- Если введено название и не прочитано ни одного сайта, Shark ищет точное совпадение компании в [Wikidata](https://www.wikidata.org/wiki/Help:Data_access) и выделяет найденные сайты как кандидатов. Это не выписка из реестра.
- Есть локальный импорт CSV [Blackbird](https://github.com/antoniaci/blackbird), [Sherlock](https://github.com/sherlock-project/sherlock) и [Maigret](https://github.com/soxoj/maigret). Shark не запускает эти программы сам. Он сверяет ссылки в их отчётах с опубликованными ссылками на проверенном сайте. Совпадение одного ника на разных площадках не считается связью.
- Brave Search с ключом просматривает больше кандидатов и ищет номер также в распространённом формате с пробелами для +7 и +371. Обычный HTML без структурированной карточки компании тоже подходит, если найден явный регистрационный реквизит и совпадает исходный контакт.

```sh
phonehost investigate --handle microsoft --company Microsoft --profiles
phonehost investigate --site 'https://shop.example.org' --profile-report blackbird.csv --profile-report sherlock.csv
```

### Своя точка доступа

Открой `phonehost console` и пункт **2. Точка доступа**.

- **s** открывает системный экран раздачи интернета. Переключатель на нём включает Android. Вернись в Shark, чтобы обновился статус.
- **a** на прошивках с подходящей командой Android и доступом `su` создаёт отдельную локальную точку Shark с WPA2 и случайным паролем. Это не гарантирует раздачу интернета или получение адреса на всех прошивках. Shark проверяет, появился ли активный SoftAP.
- **v** включает чтение системных данных через `su`, если Android не показывает статус или список без root.
- Список обновляется на открытом экране. Номер строки открывает карточку IP, подсеть, MAC, состояние кэша и имя, когда Android отдал его через DHCP. Статус клиента из кэша или аренды не заменяет точный счётчик подключений.
- При наличии данных Shark показывает входящую сеть **раздающего** телефона. По локальному IP не определяется оператор SIM подключённого устройства. Данные карточки не отправляются наружу. Отдельная клавиша **i** запрашивает внешний IP самого телефона и показывает регистрацию его сети по RDAP. Это адрес выхода Termux, который может отличаться от маршрута раздачи.

```sh
phonehost hotspot status --root
phonehost hotspot status --root --json
phonehost hotspot settings
```
